# Welcome to Draho

![Drahomil on a roof above an old Flemish city at night](.gitbook/assets/drahomil-rooftops.jpg)

**Draho** is a mobile game about **Drahomil**, a black house cat who works as a mouse bounty hunter.
Neighbours, shops and old buildings hire him to clear their mice. Each finished job opens a new place to explore.

Drahomil is a real cat. He lives in Flanders, Belgium, and the first level of the game is his own home and garden.

## Quick facts

| | |
|---|---|
| **Genre** | Cozy 3D adventure with stealth and hunting |
| **Platform** | iPhone (landscape). A web test build runs in any modern browser |
| **Engine** | Unity 6 |
| **Developer** | Jim, a solo hobby developer from Belgium |
| **Started** | October 2026 |
| **Status** | Early development. Playable test build, free |
| **Price model (plan)** | Free to play with cosmetic purchases only. No pay-to-win |
